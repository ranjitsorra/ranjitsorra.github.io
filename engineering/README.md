# Engineering notebook

Publish **only independently developed or explicitly cleared material**. Never upload employer files, confidential schematics, proprietary specifications, internal test results, or NDA-covered details.

For each experiment, create a folder such as `engineering/ltspice/buck-converter/` containing `README.md`, `circuit.asc`, and optional exported plots. Add a record to `data/engineering.json` with fields `title`, `summary`, `tags`, `page`.

Recommended experiment metadata: objective, topology, operating conditions, device models and their sources, control method, assumptions, key waveforms, losses, simulation vs measurement status, limitations, lessons learned, and file provenance. Do not claim simulation results without supporting data.

For company projects, publish only employer-approved high-level summaries. Public GitHub history is not a secure place for confidential data.
