# Personal reading journal

Add books to `data/books-english.json` or `data/books-telugu.json` as objects with `title`, `author`, `status`, and optional `genre`, `finished`, `rating`, `notes`. Example:

```json
[{"title":"Example title","author":"Example author","status":"Completed","genre":"Fiction","finished":"2026-11","rating":"4/5","notes":"My short reflection."}]
```

These lists are primarily a personal reference; ratings and notes are optional. Avoid copying copyrighted passages or book covers without permission.
